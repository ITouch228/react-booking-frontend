# Система бронирования помещений

SPA-приложение для бронирования помещений с ролями пользователей, фильтрацией и тестированием бизнес-логики.

🔗 Онлайн-версия: https://booking.itouch.pw

---

## 🛠 Стек

- React
- TypeScript
- Vite
- React Router
- CSS Modules
- Vitest
- React Testing Library

---

## 🧠 Архитектура

Структура проекта:

components/  
hooks/  
services/  
pages/  
types/  
utils/  

### Подход к разработке

- Разделение UI и бизнес-логики
- API-слой вынесен в services/
- Бизнес-логика инкапсулирована в кастомных хуках
- Типизация API-ответов
- Ролевой доступ (гость / пользователь / администратор)
- Защищённые маршруты

---

## ⚙️ Решённые задачи

- Управление временными слотами без конфликтов
- Синхронизация состояния при обновлении страницы
- Фильтрация и поиск без дублирования логики
- Обработка асинхронных запросов
- Тестирование пользовательских хуков

---

## 🧪 Тестирование

- Unit-тесты (Vitest)
- Тестирование компонентов (Testing Library)
- Проверка бизнес-логики хуков
- Тестирование API-слоя

---

## 📊 Объём проекта

- 40+ компонентов
- 6+ кастомных хуков
- Тестирование ключевой логики
- Модульная структура

## 🚀 Запуск

```bash
npm install
npm run dev
```

Проект демонстрирует подход к построению масштабируемого SPA-приложения с разделением ответственности и тестированием.
