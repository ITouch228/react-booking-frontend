# Система бронирования помещений

Современное и функциональное приложение для бронирования помещений, созданное с использованием React, TypeScript и Vite. Это приложение позволяет пользователям просматривать, бронировать и управлять резервированиями различных типов помещений, включая переговорные комнаты, рабочие места, студии и спортивные объекты.

## 🚀 Возможности

- **Аутентификация пользователей**: Безопасная система входа и регистрации с контролем доступа на основе ролей
- **Просмотр помещений**: Просмотр различных типов помещений с подробной информацией и характеристиками
- **Гибкое бронирование**: Бронирование помещений с гибкими временными интервалами или фиксированными периодами
- **Реальное время доступности**: Проверка доступности помещений с обновлением в реальном времени
- **Управление профилем**: Управление пользовательским профилем и просмотр истории бронирований
- **Адаптивный дизайн**: Полностью адаптивный интерфейс, работающий на всех устройствах
- **Современный UI/UX**: Чистый и интуитивно понятный пользовательский интерфейс с плавными взаимодействиями
- **Фильтрация помещений**: Расширенная фильтрация помещений по различным критериям (локация, вместимость, тип, цена и т.д.)
- **Поиск и навигация**: Интуитивная система поиска и навигации по всем доступным помещениям
- **Интеграция с календарем**: Визуализация доступных временных слотов через удобный календарь
- **Управление временными слотами**: Интерактивный слайдер для выбора точного времени бронирования

## 📦 Установка

1. **Клонируйте репозиторий**

   ```bash
   git clone <repository-url>
   cd pet-project
   ```

2. **Установите зависимости**

   ```bash
   npm install
   ```

3. **Настройте переменные окружения**
   Создайте файл `.env` в корневой директории и добавьте переменные окружения:

   ```
   VITE_API_URL=your_api_base_url
   ```

4. **Запустите сервер разработки**

   ```bash
   npm run dev
   ```

5. **Откройте браузер**
   Перейдите по адресу `http://localhost:5173`, чтобы посмотреть приложение

## 🧪 Тестирование

Этот проект включает в себя комплексную систему тестирования:

- **Модульные тесты**: Запускаются с помощью Vitest
- **Компонентные тесты**: Используя React Testing Library
- **Отчеты о покрытии**: Генерация отчетов о покрытии тестами
- **Тесты пользовательских хуков**: Проверка логики бизнес-логики

```bash

npm run test:ui

# Генерация отчета о покрытии
npm run test:coverage
```

## 🧩 Ключевые компоненты

### Пользовательские хуки

- `useAuth` - Управление состоянием аутентификации
- `useRooms` - Получение и управление данными о помещениях
- `useBookings` - Обработка данных о бронированиях
- `useTimeslots` - Управление временными интервалами
- `useLocalStorageState` - Сохранение состояния в локальном хранилище
- `useRoomFilters` - Управление фильтрами поиска помещений

### Страницы

- `HomePage` - Главная страница с просмотром помещений
- `LoginPage` - Аутентификация пользователей
- `SignUpPage` - Регистрация пользователей
- `ProfilePage` - Управление пользовательским профилем
- `BookingPage` - Процесс бронирования помещения
- `ConfirmationPage` - Подтверждение бронирования

### Компоненты

- `TimeSlotSlider` - Интерактивный слайдер для выбора временных интервалов
- `AppWithRouter` - Центральный компонент приложения с маршрутизацией
- `AppShell` - Обертка приложения с общими элементами интерфейса
